# IMAGE_TO_IMAGE_AI_AUTOMATICALLY_GENERATED_IMAGES

**SUPERSEDED THE SAME DAY IT WAS MADE. 2.9.2026. Do not save anything here.**

This folder was created as a landing place for the Hammerspoon driven Image to Image runs, on the
assumption that a delivery needed somewhere to sit between arriving and being filed.

**Baba corrected it within the hour, and the correction is right.** There is no in between. The
automated run saves a frame and pushes it **straight to `markoboskoauroville/BRAIN_BRAKE_ORIGINALS`**,
into the scene folder named in the batch, and that is the end of it.

## WHY THE CORRECTION IS BETTER THAN WHAT IT REPLACED

**A doorstep is still a second place a frame can be.** The README that used to sit here spent most of
its length explaining that this folder was not a home, that files must leave it, and that an
accumulating doorstep quietly becomes an archive nobody maintains. All of that effort was spent
defending a step that did not need to exist.

**Removing the step removes the problem instead of managing it.** One home, one push, one answer to
where a frame lives. On 2.9.2026 the project spent a long session pulling 160 originals out of two
places into one, and adding a third place hours later would have started the same drift again.
